# UX 2 canvas source (cast-d2o)

Snapshot of the "Castcorder UX 2: home, call, contacts" design canvas, taken 2026-11-24:
https://claude.ai/artifact/QRpduNS1CvaoLSEj7rQVBe (private until shared).

`canvas.json` lays out the artboards and the notes; each `*.dc.html` is one artboard. They
load the canvas runtime (`./support.js`), which is not in this repository, so open the canvas
link to view them. The text summary is "UI layout v2" in [docs/design.md](../design.md).
Implementation: epic cast-n56, plus cast-40e.13 and cast-40e.14.
